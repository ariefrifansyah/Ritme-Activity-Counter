# Penerapan desain final Ritme

Desain implementasi ini mengikuti mockup terbaru tiga layar dengan gaya premium minimalis.

- Home: satu panel statistik emerald berisi 2 metrik, pencarian aktivitas, list aktivitas, FAB hijau gelap.
- Form: judul dan deskripsi rata tengah, kartu nama aktivitas, tiga pilihan cepat Running/Reading/Study, tombol Simpan.
- Detail: ikon aktivitas rata tengah, angka besar pada panel emerald, tombol (+)/(-) simetris, Reset/Hapus terpisah.
- Aktivitas contoh: Morning Run (8), Read Book (3), Drink Water (5).
- Fitur UTS masih aktif: tambah/edit/hapus, reset/konfirmasi, batas minimum 0, SnackBar, ChangeNotifier/MVVM.
- 8 file Dart saja di folder lib; tidak menambah package.

Catatan: gambar mockup adalah acuan visual, bukan screenshot aplikasi berjalan.
