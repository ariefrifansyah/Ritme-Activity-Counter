SCREENSHOT ASLI UNTUK PENGUMPULAN UTS
====================================

Folder ini disediakan untuk screenshot yang diambil SETELAH menjalankan
aplikasi pada emulator atau perangkat. Silakan simpan:

  01_home.png
  02_tambah_edit_aktivitas.png
  03_detail_aktivitas.png

Cara mengambil screenshot emulator Android:
1. Jalankan flutter run.
2. Buka halaman Home lalu screenshot.
3. Tekan Tambah aktivitas, isi contoh, screenshot formulir.
4. Buka aktivitas, screenshot halaman Detail dengan counter.

File pada folder docs/preview_desain hanya mockup visual, BUKAN
screenshot aplikasi Flutter yang benar-benar dijalankan.
